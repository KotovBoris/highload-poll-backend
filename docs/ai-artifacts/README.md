# Артефакты работы с ИИ

В этом каталоге сохраняются все артефакты работы с ИИ в соответствии с
требованиями задания («Все артифакты работы с ИИ должны быть в сдаваемом
репозитории, не надо их скрывать»).

## Формат

Основной артефакт — [`work-log.md`](work-log.md): хронологический лог работ,
выполненных с помощью ИИ. В нём фиксируются:

- этапы работы (проектирование, реализация, тестирование и т.д.);
- краткое содержание каждого шага;
- затраченное время.

Полные текстовые диалоги с ИИ намеренно не включены в репозиторий из-за
большого объёма и отсутствия удобного экспорта. При необходимости полные чаты
могут быть предоставлены проверяющим по запросу.
